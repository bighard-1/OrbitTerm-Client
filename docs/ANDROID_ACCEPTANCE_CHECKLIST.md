# Android 真机验收清单

适用版本：当前 Android debug 包。此清单不要求清除应用数据、删除资产或切换账号。

## 准备

- 使用已登录、已解锁的现有测试账户。
- 保留至少一台可连接的测试服务器；不要编辑生产资产。
- 上传和下载只使用专用测试目录与可删除的测试文件。
- 每项记录“通过 / 失败 / 跳过”和截图或错误代码。

## 应用与主题

- 冷启动后进入解锁或主页面，不闪退。
- 依次选择浅色、深色、跟随系统和五种界面配色；返回服务器、会话、SFTP、Docker、设置后确认文本、图标和反馈仍清晰可读。
- 前后台切换、旋转屏幕、返回键不会要求无故重新输入主密码，也不会丢失当前页面。

## 无障碍、屏幕与输入

- 将系统字体调至 200%，依次检查登录、服务器、会话、SFTP、Docker 和个人中心：标题、状态、主要操作与确认按钮完整可达，不被裁切或相互遮挡。
- 在窄屏、横屏和分屏中打开会话：无活动会话时可通过底部导航离开；有活动会话时终端、预输入栏和扩展键栏均不覆盖系统导航或软键盘。
- 开启 TalkBack：逐项聚焦页面标题、连接状态、空态、错误/成功反馈、危险操作确认和模块切换；每项均应有可读名称、状态或操作结果，不能只通过颜色表达安全状态。
- 接入硬件键盘后，在已验证终端中验证 Ctrl+C、Ctrl+D、Ctrl+L、Enter、Backspace、Delete、Tab、Esc、Home、End、Page Up、Page Down 及中文输入；软键盘显示/隐藏和硬件键盘切换时，预输入栏与扩展键栏不应遮挡终端。
- 终端辅助说明不得朗读远端命令输出、主机地址、用户名、路径或凭据；复制、粘贴和发送仍必须由用户明确触发。

## 资产与 SSH

- 在资产页展开和收起分组；长资产名、连接状态、编辑按钮均可见。
- 首次连接显示主机密钥指纹；复制指纹、信任、取消分别有效。
- 使用错误认证信息或不可达地址确认显示连接失败与诊断代码，且不会产生会话。
- 成功连接后打开终端；返回服务器与关闭会话的行为不同且符合按钮文字。

## 终端与多会话

- 在两台已连接资产间切换会话，标题、SSH 状态和当前模块同步更新。
- 输入 `pwd`、`whoami`，确认输入、回显、滚动历史、回到最新输出、清屏、复制粘贴、扩展键和命令片段均可用。
- 切换到监控后再切换另一会话，确认新会话开始采样，旧会话数据不会短暂显示为新会话数据。

## SFTP 与传输队列

- 进入目录、返回上级、创建、重命名、权限修改、删除文件、递归删除测试目录均可用。
- 上传和下载测试文件，确认活动进度、取消、完成反馈与大小单位正确。
- 连续提交两个测试传输，确认队列顺序、移除等待项、暂停后的继续和失败后的重试。
- 多选文件和目录后下载 ZIP；SFTP 页头的更多菜单可访问新建和上传操作。

## Docker 与监控

- Docker 空列表、加载失败和已有容器三种状态的文案与反馈清晰。
- 对测试容器执行启动、停止、重启、暂停/恢复；操作进行中不会重复提交。
- 日志可滚动，自动刷新可切换，最新日志按钮能回到底部；详情能复制容器 ID。
- 监控在运行、暂停、首次读取、读取失败之间切换时布局稳定；刷新已有数据不应将图表和指标整体挤动。

## 同步与安全

- 断网后执行同步，确认“等待网络 / 同步失败”反馈与重试入口；恢复网络后再次同步。
- 测试同步冲突时分别选择保留本地和保留云端，确认结果符合选择。
- 生物识别、锁定应用、切换账号、登录密码变更和主密码轮换仅在有可恢复测试条件时执行。

## 通过标准

- 无闪退、ANR、凭据泄露或未授权连接。
- 所有可执行项均有明确的进行中、成功、失败或空态反馈。
- 真实服务器的上传、下载、取消、队列与进度需在真机网络环境单独验收；不通过时附带时间、设备型号、网络条件和诊断代码。
- P2 无障碍与输入体验的真实设备结果写入 `ANDROID_REAL_DEVICE_TEST_RECORD.md` 的 A01–A07；自动化布局回归通过不替代该记录。
