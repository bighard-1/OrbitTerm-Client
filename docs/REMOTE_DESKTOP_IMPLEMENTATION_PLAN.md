# OrbitTerm 跨平台远程桌面实施方案

## 一、调整后的范围

### 控制端

- Windows、macOS、未来 Linux 桌面端；
- iOS、Android 移动端。

### 被控资产

- Windows：RDP/NLA；
- Linux：由目标机提供 RDP 服务（例如 xrdp）；
- macOS：首期不提供图形远控，但继续完整支持 SSH、SFTP、Docker 与监控。

macOS 客户端仍可连接 Windows/Linux 的 RDP 资产。首期不引入 VNC，避免同时维护两套显示、输入、证书和移动端手势协议栈。

## 二、统一架构

```text
资产与 E2EE 同步契约（transport = rdp）
                  │
       RemoteDesktopSessionController
        ┌─────────┼─────────┐
   能力/安全策略  会话状态机  设备偏好
        │          │          │
 Windows 原生宿主  FreeRDP 适配器  移动端输入适配
                  │
         Windows / Linux RDP 目标
```

业务层只认识统一会话状态：待连接、证书待确认、认证中、在线、重连中、已断开和失败。平台适配器负责画面、输入、剪贴板和系统窗口，不得自行读取同步服务或绕过凭据库。

## 三、平台实现

### Windows

- 保留现有 Microsoft RDP ActiveX 独立原生窗口；
- 修复并固化 NLA、证书“继续/取消”、DPI、全屏和多显示器行为；
- 凭据仅从当前用户 DPAPI 读取，不写命令行或明文 `.rdp` 文件；
- 后续为与其他平台一致的会话状态和错误代码增加适配层。

### macOS

- 使用 FreeRDP 客户端库连接 Windows/Linux RDP 服务；
- SwiftUI 仅承载原生渲染视图，不在视图层实现协议；
- 支持键盘映射、剪贴板、缩放、全屏、Retina 和多显示器；
- 不提供连接 macOS Screen Sharing/VNC 资产的入口。

### iOS / Android

- 使用同一 FreeRDP 核心能力，通过各自 Native View 承载；
- 仅在 RDP 工作区允许横屏，离开工作区恢复应用竖屏策略；
- 提供“触控板模式”和“直接触摸模式”、软键盘、组合键工具栏、双指滚动与缩放；
- 前后台切换时暂停画面并按策略重连，不伪装持续在线。

### 未来 Linux 客户端

- 复用 FreeRDP 适配器和统一会话控制器；
- 凭据存储接入 Secret Service/KWallet；
- Wayland/X11 只影响窗口和输入适配，不改变同步信封。

## 四、安全与同步

- RDP 资产与 SSH 资产共用账户作用域、E2EE 上传/下载、冲突合并和删除墓碑；
- 本机专用资产不上传；退出账号后其他账户不可见、不可连接；
- NLA 默认强制开启；证书异常必须由用户确认，且按资产记录信任；
- 剪贴板默认开启，磁盘/打印机/音频重定向默认关闭并在启用时说明风险；
- RDP-over-SSH 只能复用已验证 SSH 隧道，不允许另起未验证的系统 SSH 进程；
- 不支持 RDP 的版本必须保留同步资产并明确提示，不得降级为 SSH。

## 五、交付阶段

1. **契约基线**：四端识别并安全同步 `rdp`，Windows 取消本机专用限制，不支持端 fail-closed。
2. **Windows 收口**：统一状态机、证书/NLA、全屏、DPI、断线重连和诊断。状态机、证书确认状态、重连、全屏与脱敏错误反馈已完成代码和 Release 构建验证，尚需实机交互矩阵验收。
3. **macOS 控制端**：FreeRDP 原生视图、键鼠、剪贴板、全屏和 Windows/Linux 真机矩阵。Apple/Android 共用会话契约与 fail-closed 适配接口已经建立；下一步才链接经审计的 FreeRDP 二进制与原生渲染视图。
4. **移动控制端**：iOS/Android 渲染、手势、输入法、RDP 工作区横屏和生命周期。
5. **Linux 控制端预留落地**：凭据适配、窗口适配与打包。
6. **高级能力**：RDP-over-SSH、网关、显示器选择和受控重定向。

## 六、发布门禁

- Windows/Linux 目标 × 已实现控制端的连接、证书、认证、重连和休眠恢复矩阵；
- 四端新增、编辑、删除 RDP 资产的加密同步与墓碑回归；
- 不支持端不得出现 SSH 握手、SFTP、Docker 或监控通道；
- 凭据、画面、剪贴板和远端路径不得进入日志或诊断；
- 移动端旋转、软键盘、手势、前后台与内存压力真机测试；
- macOS 图形目标不得出现在支持列表或自动探测结果中。
