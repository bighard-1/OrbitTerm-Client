## 记录规则

- 只记录平台、构建状态、可复现步骤与脱敏现象；不得写入账号、设备标识、端点、资产名称或凭据。
- `通过` 仅代表本轮 Apple 观察项，不得替代 `REAL_DEVICE_ACCEPTANCE_PROTOCOL.md` 要求的五端墓碑矩阵。
- 当前工作区有未提交变更。因此本轮安装包用于诊断和交互验收，**不是**可关闭 P0 的固定候选构建。

| A-OBS-02 | P2 | macOS | FreeRDP 上游构建出现已弃用证书回调 API 的编译警告。 | 本轮构建与运行时自检未失败；仍需在 Windows/Linux 的对应远程桌面栈中核对证书处理行为。 | 观察中。 |
| A-OBS-03 | P2（环境） | iOS | 真机 UI 执行期间，Xcode 偶发报告调试器元数据 / DeviceSupport 定位警告。 | 11 项测试均完成且无失败；当前不构成产品缺陷，但后续升级 Xcode 或 iOS 后应复跑。 | 观察中。 |
