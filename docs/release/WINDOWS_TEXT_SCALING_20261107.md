## 后继源码修订

基于 `ec52e49` 修正标题栏／模块文字按钮的固定宽高：82／112 点作为基准最小宽度，标题栏 28 点作为按钮最小高度，允许随系统文字增长。标题栏行按内容测量、保留 36 点基准高度；从终端全屏返回也恢复自动测量。标题栏命令区受窗口可用宽度约束，可水平滚动，仍保留原生窗口按钮留白及至少 24 点拖拽区；不缩小文字、不关闭系统文本缩放、不隐藏账户入口。

共享视觉合同仍检查按钮顺序及基准最小宽度，Windows 放大文字的可达性规则同步写入[桌面视觉契约](../DESKTOP_WORKSTATION_VISUAL_PARITY.md)。模块按钮仅移除固定 Width，既有最小尺寸、危险动作与确认逻辑不变。

**本地验证**：两份 XAML 的 XML 解析、跨桌面视觉合同、桌面稳定性前置合同及差异检查通过。纯 WinUI 布局修订未新增镜像实现的 ViewModel 单测；原生 403 项及 WinUI 编译由新提交 CI 执行。**修订后原生构建、签名安装、100%／150% 文本 GUI 均待后继固定候选回执**，尚不能关闭裁切失败。没有私有 UI 测试开关加入源码。
