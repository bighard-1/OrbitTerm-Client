## OpenSSH 自动化：真实传输通过

已有 opt-in 脚本 `scripts/security/run_openssh_smoke.sh` 生成独立 Ed25519 用户密钥及 A／B 两套主机密钥，临时 sshd 仅监听回环高端口、仅允许当前测试用户公钥认证，禁用密码／PAM／转发。使用夹具专属信任库；不复用用户信任记录。

在启动临时监听前，Release 测试程序离线预构建通过；随后整套执行受 600 秒进程组期限约束，实际 2.776 秒、退出 0。四次精确运行的被忽略集成测试均实际执行 **1／1、0 失败／忽略**，不是普通套件中的 ignored 结果：

| 场景 | 实际断言结果 |
| --- | --- |
| unknown→persist→trusted | 未知主机返回受检 challenge、接受前没有成功认证；显式持久化独立 0600 信任库后测试及连接成功；受检 PTY、SFTP 列目录／下载、已有目标保留、远端临时文件独占及取消清理、受检 exec、非零退出／多行拒绝、会话释放／重连全部通过 |
| changed | 同一回环端口替换为主机密钥 B，受检连接按 changed 拦截，返回前后指纹且没有成功认证 |
| revoked | 独立撤销记录命中 B，按 revoked 拦截，无信任／替换能力且没有成功认证 |
| Release legacy-no-socket | 无 feature Release 的旧 SSH 测试／连接、SFTP／exec 全部返回禁用错误，sshd 新连接计数不增加；随后受检调用能够创建连接并返回未知主机 challenge，证明观察通道有效 |

**显式限制**：Monitor 因 macOS 夹具缺少 Linux 采样命令返回允许的稳定结构化错误，不算真实监控采样通过；Docker 命令不可用，记录 skipped，不算 Docker 功能通过。本轮仅 Ed25519、当前本机用户、回环真实 OpenSSH 传输；不覆盖 OTP、其他密钥算法、跳板机、各端客户端 GUI 或真实设备性能。

**清理核对**：退出后临时根目录为空、夹具 sshd 进程不存在；用户 SSH 配置／信任文件的存在性及摘要与执行前完全一致。进程组超时包装确保结束后不残留子进程，未提高权限、未开启系统远程登录、未更改系统配置。临时密钥随夹具删除，保留脱敏阶段 JSONL 及测试日志。

这补齐本机原生 OpenSSH 的 RC 功能证据；先前 Security `42477833346` 的条件式 OpenSSH job 仍是 skipped，不能改写为该云端 job 已运行。已有六项必跑门禁成功结论见 [CI 最终回执](CI_DEPENDENCY_FETCH_20261108.md)。

## 复审发现：性能证据校验器仍需整改

以下为**虚构文件的反例自动化**，不是任何设备、性能或发布通过证据。原始输入、退出码和结果分别留存，不提交到源码中的真实性能证据位置：

1. `verify_apple_device_slo.py`：八个必需场景均提供负响应时间、负 CPU／内存／hitch 数，且没有构建／平台元数据，仍退出 0，输出八场景通过。说明仅做阈值上界比较不足以验证证据。
2. `verify_desktop_concurrency_evidence.py`：首次加入负取消时间被正确拒绝，失败保留；只将取消时间改为合法 0 后，九份数据仍包含负点击／切换时间、`NaN` 吞吐和平台间不同构建 SHA，脚本却退出 0。不能把首次拒绝当作后续这些输入也已被拒绝。

**开放问题，尚未修复**：需严格拒绝非有限数值、布尔值伪装指标、负响应／资源指标、缺失／错误元数据、重复记录及同一验收组混合候选；Apple 还需明确分别覆盖 macOS／iOS 和三次测量的契约。输入结构错误和敏感字段应安全失败，不能靠输出“passed”证明真实性。下一步优先补正反例及修复校验器，再开始正式性能采集；不通过降低 SLO 或填写占位值关闭性能阻断项。
