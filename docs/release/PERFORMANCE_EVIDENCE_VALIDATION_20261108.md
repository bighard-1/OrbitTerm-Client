# 性能证据校验整改（2026-11-08）

## 问题与范围

本轮只改性能证据读取／校验／摘要工具、调用入口、测试与验收文档。无客户端功能或二进制更新，原两份 Android JNI 改动保持未提交；K60 USB 未出现，没有产品 GUI／真实设备性能采样或线上操作。此前 `ff7b254` 全 CI 结果仍只属于旧源码，不能代替本轮新工具验证。

## 修订合同

- 两个校验器均要求显式 `--expected-build-commit` 完整 40 位小写 SHA；每份记录逐项匹配，不允许短 SHA、缺失、混合候选或只验证格式。
- 有限大小读取、严格 JSON 对象及字段白名单，拒绝重复 JSON 字段、非标准 NaN／Infinity、浮点溢出、过大输入、错误编码／结构、额外及敏感字段。整数／指标不接受布尔值。非有限／负指标被拒绝，内存为正整数字节数；场景／平台先校验类型，不因列表等非法值抛未处理异常。
- 桌面并发保留 Win10／Win11／macOS 各三轮及原全部阈值；重复记录不能补齐缺失轮次，九份记录必须同候选。
- Apple schema v2：macOS／iOS 各八场景、各三轮，共 48 份独立实测记录。三次响应取中位数、CPU 取三次平均值的算术均值、内存／帧率／卡顿取最差值，保持原 SLO 数值。新增正整数 sample_count 和两次 capture 的 SHA-256，禁止跨记录／capture 复用摘要。旧 v1 八份聚合文件不自动升级，须从留存实测 trace 重新生成或重新采集。
- Apple 发布门禁显式传入当前检出提交；采集摘要工具新增候选／平台／轮次及帧捕获参数，输出与消费者完全一致的 v2。非有限／负／非整数 footprint、空／符号链接 trace 被拒绝，摘要散列流式读取；导出或校验失败保留原摘要，成功后原子替换。
- 校验／采集错误只输出已知字段名和固定分类，不回显证据路径、非法原值、额外字段名或 xctrace 错误正文。CLI 参数错误也不回显输入。私有原始 trace 仍不进入仓库或诊断导出。

本轮要求更完整的证据并拒绝非法输入，不降低阈值、不更改 P0 状态。合法记录的结构及阈值通过不证明人工读数真实、摘要对应正确应用／场景或测量方法可靠；发布负责人仍须对照固定签名候选和原始 trace 审核。合成正例只是测试，不是实机性能通过。
