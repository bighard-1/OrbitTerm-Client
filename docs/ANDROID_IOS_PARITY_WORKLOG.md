# Android 与 iOS 行为对齐工作台账

## 目标与原则

Android 以 iOS 移动端的功能语义、信息架构和关键操作结果为基准；Android 的系统返回、输入法、无障碍、权限和窗口行为维持原生实现。任何“看起来相似”但会改变数据、连接安全边界或用户操作结果的实现都不视为完成。

发布级的逐项状态、负责人和验收条件见 [Android / iOS 行为对齐矩阵](ANDROID_IOS_BEHAVIOR_ALIGNMENT_MATRIX.md)；本文件仅保留过程台账与真机验收说明。

## 分阶段验收

1. **壳层与资产（已完成）**：五入口、服务器分组/搜索/批量操作、编辑与连接分离、Host Key 信任流程。  
2. **会话工作区（已完成）**：会话选择、关闭、重新连接、终端/快捷指令/监控/Snippets 四个模块及全屏输入体验。  
3. **SFTP（代码与模拟器验收完成）**：绑定当前已验证会话，目录浏览、传输、文件操作和批量操作；真实服务器真机验收待执行。  
4. **Docker（已完成）**：绑定当前已验证会话，容器列表、详情、日志与受控操作。  
5. **个人中心与设置（已完成）**：账户入口、应用与终端外观、安全和诊断。  
6. **跨端回归（待真实设备收尾）**：用同一份逐项用例在 Android 真机和 iOS 上验证关键结果；仅在差异有明确平台理由时保留差异说明。

## 项目收尾统一验收：真实服务器 SFTP 大文件

当前模拟器验证不替代真实网络与 Storage Access Framework 行为。该项已留档，待 Android 端功能开发完成后，由真机统一验收：

- 上传、下载大文件的实际字节进度：上传应显示已传输/总大小；无法可靠获得远端大小的下载只显示已传输量。
- 活动传输取消：取消后不出现半成品目标文件；上传临时远端文件与下载应用内暂存文件均须清理。
- FIFO 队列：顺序执行、等待项移除、失败暂停、显式继续及切换/断开会话后的安全终止。
- Android 10 与 Android 15 真机的 SAF 选取、目标文件写入、前后台切换和网络中断恢复提示。

## 本轮已完成的行为变更

- 底部导航由“资产 / 会话 / 工具 / 设置”改为与 iOS 对应的“服务器 / 会话 / SFTP / Docker / 个人中心”。
- 服务器卡片的主要点按行为改为连接；编辑不再占用主要路径。
- 会话页改为自身拥有工作区栏，支持选择现有会话、关闭当前会话和返回服务器。

## 当前未宣称完成的项目

- 真实服务器上的大文件上传、下载、取消、队列顺序和实际字节进度尚待真机验证。
- Android 10 与 Android 15 真机的 SAF、前后台切换、网络中断及跨账户竞态场景尚待最终回归。
- 发布签名、商店材料、灰度和 CI 发布门禁不属于当前本机开发验收范围。

## 2026-07-27：项目收尾保留项——真实传输验收

- 真机与真实服务器的 SFTP 大文件传输验收已正式延后至项目收尾统一执行；它不是当前功能开发的阻塞项，也不以模拟器结果替代。
- 验收范围固定为上传、下载、取消、FIFO 队列、进度、前后台切换与 Wi-Fi/蜂窝网络切换；同时覆盖 Android 10 与 Android 15。
- 使用 [真实设备与服务器验收记录](ANDROID_REAL_DEVICE_TEST_RECORD.md) 留存脱敏的环境、时间、最后进度、截图与诊断代码；失败记录不得被后续重试覆盖。

## 2026-07-26：Android 单跳跳板机（ProxyJump）

- Android 已原生接入 iOS 同一套单跳跳板语义：跳板与目标资产独立保存凭据、独立校验主机密钥；目标 SSH 会话建立在跳板的 `direct-tcpip` 通道内。
- 资产编辑器可启用跳板、配置地址/端口/用户名/私钥或密码认证、私钥口令、仅密钥策略和私钥失败后的可选密码回退；跳板私钥可从 SAF 文件选择器导入。
- 跳板元数据写入 Room v7，凭据只写 Android Keystore；加密同步载荷包含跳板配置及其独立凭据。禁用或更换跳板会清除不再引用的旧跳板凭据。
- 连接改走 checked SSH v2 JNI ABI。跳板主机密钥信任完成后会重新执行完整链路，随后再对目标主机发起独立信任；SFTP、Docker、终端和批量命令均复用最终验证后的会话。
- 已完成 core 跳板 FFI 测试、Android 单元测试、Debug 构建及 arm64-v8a/x86_64 JNI 符号检查；待真实跳板与目标服务器进行端到端验收。

## 2026-07-26：跳板机模块审查修复

- 修正跳板私钥认证的可选密码回退：只有策略允许时才把回退密码交给 core；策略关闭时不持久化该回退密码。
- 同步冲突影子改为比较跳板路由语义（地址、端口、用户名、认证策略），不比较带账户命名空间的本地凭据 ID，避免跨端同步产生伪冲突。
- 云端替换或移除跳板、以及本地禁用或替换跳板后，都会删除不再引用的 Keystore 跳板凭据。
- 本地保存先完成跳板配置与凭据前置校验，避免无效草稿留下孤立的目标凭据。

## 2026-07-27：服务器分组与应用主题对齐

- 服务器分组展开状态已从页面局部状态提升到资产 ViewModel：与 iOS 一样默认收起，并在切换会话、SFTP、Docker 或个人中心后保持用户选择。
- Android 保留“跟随系统 / 浅色 / 深色”外观模式，同时补齐 iOS 的五套应用配色：天空糖果、翡翠流光、蜜桃晨光、薰衣草雾、冰川薄荷。
- 应用配色独立持久化，不改变终端 ANSI 主题、字体大小或安全语义。

## 2026-07-26：批量命令安全语义复查

- 已对照 iOS `BatchCommandRunnerView`：所有目标均必须已有完成主机身份验证的 SSH 会话；不能自动连接，也不能静默跳过未连接目标。
- Android 已改为在执行前原子校验全部选中资产。任一资产缺少已验证会话时，整批命令不执行，并显示缺失会话数量与修复指引。
- 同一资产只会解析到一个活动会话，避免重复下发命令。
- Android 的批量选择模式已具备“选择此分组”入口，因此无需为该项重复新增一套分组选择界面。

## 2026-07-26：Docker 操作边界复查

- iOS 与 checked native core 均支持 Docker `kill`；Android 客户端此前未在参数白名单和界面中开放。
- Android 现仅在运行中容器的详情页提供“强制停止”，并要求二次确认；该操作不会挤占列表的日常启动、停止、重启和暂停入口。
- checked native bridge 仍会验证容器标识、操作枚举与已验证 SSH 会话，客户端没有引入 Shell 拼接或旁路网络访问。

## 2026-07-26：SFTP 在线文本编辑保存语义

- checked SFTP 写入会在发布替换文件前校验读取时的条目快照，远端文件已变更时返回 `sftp_entry_changed`，不会盲目覆盖。
- Android 编辑器改为只在保存成功后关闭；保存失败、冲突或临时目标占用时保留用户当前草稿，并在编辑器内说明原因。
- 保存进行中会暂时禁用再次保存和关闭操作，避免并发写入或请求尚未完成时误丢草稿。

## 2026-07-26：SFTP 打包下载队列一致性

- 目录或多项目“下载为 ZIP”已纳入与普通上传、下载相同的单任务 FIFO 队列；不会再绕过队列并发占用 SFTP 会话。
- ZIP 内的每个远端文件下载复用当前队列任务的取消标识，能够获得统一的原生传输进度与取消结果。
- 等待项、失败暂停、显式继续、会话切换时的安全终止及本地暂存清理均沿用现有传输状态机。

## 2026-07-26：SFTP 取消进度一致性

- 原生层拒绝取消（通常表示任务已接近完成）时，Android 只更新取消提示，不再使用点击取消时的旧状态回填界面。
- 因此，取消请求期间到达的最新字节进度不会被回退或覆盖。

## 2026-07-26：Docker 会话切换隔离

- Docker 容器列表、统计、操作回执和日志刷新均绑定发起请求时的已验证 SSH 会话标识。
- 会话切换后会立即取消旧日志自动刷新；迟到的旧会话响应不会覆盖新会话的容器或日志界面。
- 仅在实际底层会话变化时重置 Docker 页面，避免普通终端输出造成无谓刷新。

## 2026-07-26：账户切换中的同步隔离

- 同步启动时捕获账户作用域；资产和命令片段的后台读写均显式写入该作用域，不再依赖可能已变化的当前账户。
- 账户退出或切换期间完成的旧同步不会更新新账户的同步状态，也不会以旧凭据触发重跑或冲突回写。
- 最终真机验证需覆盖“同步进行中切换账户/退出登录”，确认旧账户数据不出现在新账户资产与命令片段列表中。

## 2026-07-26：异步会话与主密码回调隔离

- 令牌刷新、登录密码更新和主密码轮换在持久化令牌、更新 UI 或恢复内存主密码前，均确认原会话/原账户仍处于活动状态。
- 登出或账户切换后的迟到网络回调不会重新登录旧账户，也不会将旧账户主密码放回当前内存状态。
- 真机验收应覆盖：令牌接近过期时退出登录、登录密码修改中切换账户、主密码轮换中退出登录。

## 2026-07-26：锁定期间的终端打开竞态

- 终端异步打开请求现绑定发起时的会话代际；主密码锁定、登出或账户切换会使未完成请求失效。
- 若原生终端通道在安全边界之后才返回，Android 会立即关闭通道和关联 SSH 会话，而不会把它附着回已锁定界面。
- 关闭全部会话时也会清除未匹配的早期终端输出缓存。

## 2026-07-26：认证迟到回调隔离补充

- 登录请求拥有独立代际；登出后的旧登录成功或失败回调不再保存会话、激活旧账户或显示过期错误。
- 修改登录密码的失败回调同样先确认原会话仍有效，避免账户切换后向新页面写入旧账户的错误提示。

## 2026-07-28：P2 无障碍与终端输入基线

- 共享页面标题、空态标题、状态行与反馈横幅已补齐 Compose 语义：标题可被辅助服务定位，状态不只依赖颜色，成功/失败反馈通过礼貌实时区域播报。
- 终端原生视图提供不泄露输出内容的操作说明；远端输出、主机、路径与凭据不会作为辅助朗读文本暴露。预输入栏和模块切换补齐可读名称、Tab 语义与最小触控高度。
- 硬件键盘新增 Ctrl+A 至 Ctrl+Z、Enter、Backspace、Delete、Tab、Esc、Home、End、Page Up/Page Down 映射；现有 IME 提交、软键盘吸附与长按复制/粘贴逻辑保持不变。
- Android 15 仪器化测试已验证空态标题和动态反馈语义；JVM 测试已验证硬件键映射。TalkBack、字体 200%、横屏/分屏和真实硬件键盘仍按 `ANDROID_ACCEPTANCE_CHECKLIST.md` 的人工设备项验收，故矩阵状态保持“待完成”。

## 2026-07-28：P2 设计系统与视觉回归基线

- 应用层状态色已收束为 Neutral、Information、Success、Warning、Danger 五个语义令牌；状态色不参与终端 ANSI 色板计算。
- 危险确认与表单确认统一显示“危险操作”说明，使用风险色确认按钮并保留清晰的取消入口；既有调用方无需复制实现。
- 终端设置页改用共享 ANSI 色板预览；所有预置主题的终端前景与背景均由 JVM 门禁校验至少 4.5:1 对比度。
- Android 15 ARM64 模拟器新增两套无数据截图指纹基线：明亮状态/终端主题与深色危险确认。系统栏不参与截图，以避免设备时钟和导航区域产生误报。
