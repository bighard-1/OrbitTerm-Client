OrbitTerm v1.0.1 Local Validation Build
Build: 20260624

OrbitTerm 是 SSH 客户端与运维工作台，不是堡垒机或 SSH 网关。

安全与连接:
- 公开发布版启用 SSH Host Key 校验和本地 known_hosts。
- 首次连接必须明确确认指纹。
- Host Key 变更或被撤销时将阻断连接。
- Terminal、SFTP、Monitor、Docker 列表/状态/日志/操作与 Batch 命令均使用已验证会话。

本版限制:
- Telnet 默认关闭；用户可在设置中了解明文风险后主动启用，每个目标首次连接仍需确认。
- Docker rename/update 未开放。
- Quick Key 远程部署未开放。
- Batch 仅执行已建立验证会话的目标。
- checked 会话的终端分屏暂未开放。
- Android SSH 客户端不在本次发布范围。

已知限制:
- 尚未提供 Known Hosts 管理界面。
- Docker 需要已验证 workspace，并受远程 Docker 环境限制。
- Monitor 可用指标取决于远程操作系统命令支持。

安全说明:
- 不提供 Trust All。
- 不允许绕过已变更的 Host Key。
- Release 中 legacy 联网路径已禁用。
