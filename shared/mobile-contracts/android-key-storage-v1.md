# Android 自定义终端键：本机加密存储与原子迁移

2026-09-04。已接入 Android 的解锁后读取/保存路径；**没有开启云端写入**，Apple 本机存储/编辑器仍待下一阶段。

## 存储与密钥

- 继续使用同一个 `terminal_key_usage` Preferences DataStore，避免跨文件提交产生半迁移状态。
- 新字段 `terminal_keys_protected_v1_<account>` 只保存 AES-256-GCM 密文（版本头、随机 12 字节 IV、密文和 128 位 tag）。每个账户使用独立 Android Keystore alias，密钥不导出。
- AAD 为固定用途/版本前缀加账户分区，调换账户密文不能通过认证；此密钥是本机静态数据保护密钥，**不是主密码派生 E2EE 密钥**。
- 密文内部包含 schema version、账户分区、稳定 actor UUID、v1 模型、迁移前原始 JSON、迁移后编辑计数。备份不另写明文文件，也不写日志。原始备份不自动回收。
- 解密只能使用现有密钥；缺失、损坏、未知模式或认证失败均报错，不新建密钥，不从旧明文或空配置覆盖密文。
- 系统备份原已禁用，本轮补充 DataStore 目录的云备份/设备迁移排除规则。手工复制应用私有文件不能视为受支持迁移；密钥不能跨设备带走。
- 原有使用次数统计不迁入 v1、不上传云端，仍是本机统计元数据，可能包含按键标签。本轮加密保护的是完整按键配置及原始备份，不宣称所有历史统计/文件残留都已安全擦除。

## 原子迁移

1. 捕获当前已解锁账户及操作 generation/解锁序号；未解锁不迁移、不读取按键内容。
2. 在 DataStore 串行编辑事务中读取原始 JSON。已存在新密文时优先严格读取，不因其损坏而回退旧源。
3. 对旧记录做完整 v1 预检。有效时生成 actor、建立模型及原始备份，加密后立即解密并逐字段验证。
4. 仅验证成功且权限仍有效，才在**同一次事务**中写新密文、移除原明文字段；任一步失败，DataStore 不提交转换后的 preferences。
5. 整个密文文档就是迁移完成记录，不另设可能提前成功的标记。重启后直接使用原 actor 和修订状态。

无效/超限/未知旧记录暂不迁移：原数据保持在旧位置，管理页给出明确提示；仍沿用上一轮无损旧存储规则，禁止静默删除。修复后下一次解锁读取或写入可重新检查。不把这类保留情况宣称为已加密。

## 写入、锁定与回滚

- 新增/删除修改当前模型的因果修订并保留墓碑；保留原备份。每次写入先生成并验证新密文，再交 DataStore 提交。
- 解锁权限只在进程内保存。锁定/退出立即撤销；账户切换和同账户 generation 变化也使旧 lease 无效。事务变换前后、异步返回及读取发布前检查 lease，防止迟到结果更新另一账户或 UI。
- 自检发现并修复生物识别入口的相邻漏洞：解锁/启用回调绑定发起时的 Cipher 实例、账户及 generation，单次消费；锁定、账户切换和失败取消清除待完成请求。旧成功回调不能重新授予权限，同账户退出重登也不例外。硬件生物识别实际体验仍需真机验证。
- 已经开始的底层原子磁盘提交可能在锁定边界完成，但它始终写原账户分区的密文；提交返回后的旧结果不发布。这里不承诺跨线程锁定与物理磁盘写入绝对同时。
- 未解锁的订阅返回空列表/统计；没有常驻解密文档缓存。终端 UI 的 StateFlow 停止订阅后过期重放缓存；托管 String 无法承诺物理内存逐字节擦除。
- 使用次数更新不改变配置密文，所以不会重新解密和合并整份按键库。
- 提供 `rollbackUneditedMigration()` 恢复接口，仅允许迁移后编辑计数为零。恢复迁移前原文、移除新文档并设置迁移暂停标记，均在同一事务中完成。已有新更改时拒绝回滚，避免丢失进度。
- 回滚是明确恢复操作，会将原配置恢复到旧明文存储；不是读错误时的自动处理。当前未向用户开放回滚按钮，下一阶段需配合说明/确认和恢复页面。暂停后不会自动重新迁移。

## 验证与未覆盖范围

- JVM：文档/actor 重建、原文字节备份、编辑/墓碑、拒绝有损回滚、验证失败、错误账户及 lock/reunlock/generation/账户切换 lease。
- 模拟器：真实 Android Keystore AES-GCM、随机 IV、调换/篡改密文、密钥缺失不重建；实际 DataStore 原子替换、磁盘重开、锁定中断、加密验证失败、坏密文不回退、无效旧记录保留、回滚暂停和编辑后拒绝回滚。
- 测试仅使用随机测试账户、专属临时 DataStore 和测试 alias；清理只处理这些测试产物，不接触真实账号密钥/偏好。APK 覆盖安装保留 Smoke 应用数据。
- 不等同于断电/文件系统故障全覆盖或所有 Android 厂商 Keystore 真机验证；这些仍在真机清单内。

后续：Apple 等价安全存储与原生编辑器；双端冲突/导出修复与恢复入口；兼容版本策略明确后，再做账户 E2EE 上传与往返集成。
